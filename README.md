# Modern Snake Game

A polished browser-based Snake game built with HTML, CSS, and JavaScript.

## Features

- Responsive canvas-based game board
- Score counter
- Local leaderboard saved in browser storage
- Keyboard and on-screen controls
- Modern glassmorphism UI

## How to run

Open `index.html` in your browser. No build step needed.

## Controls

- Arrow keys to move
- Space to start or restart
- On-screen buttons for touch-friendly play
